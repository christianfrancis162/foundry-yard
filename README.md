Foundry Yard is a round-based tactical first-person shooter in the browser: a 36 x 30 m outdoor map with two bombsites, three lanes and a mid doorway. You and two teammates face three enemy bots. Red attacks a bombsite — stop the plant, or defuse the bomb. First to 5 round wins takes the match. Buy weapons between rounds, throw grenades, and use the shotgun up close. Built with three.js, runs offline from static files.

## Run it

```sh
node serve.ts
```
